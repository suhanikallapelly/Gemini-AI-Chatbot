# 🤖 Gemini AI Chatbot

A simple AI chatbot built with **Python, Streamlit, and Google Gemini API**.

## ✨ Features

* 💬 Chat with AI
* ⚡ Fast responses
* 🎨 Simple UI
* 🔐 Secure API key

## 🛠️ Tech Stack

* Python
* Streamlit
* Gemini API

## 🚀 Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
